# 🍽️ lunchoice（ランチョイス）

休日の昼食選びを“決定疲れ”から解放する Web 提案アプリです。  
大カテゴリ（和洋中など）と主食（米・麺など）を選ぶだけで料理候補を一覧表示。  
さらに、食べた昼食を投稿して他ユーザーと共有できる SNS 機能を備えています。

---

##  サービス概要

休日の昼食を決める際に起こりがちな  
「何を食べるか思い浮かばない」「考えるのが面倒」  
という悩みを解消するアプリです。

- **カテゴリ選択 → 候補一覧表示 → 決定**  
という最短ルートで昼食を決められます。

さらに、実際に食べた昼食を投稿し、  
**「みんなの今日の昼食」** を共有することで、  
一人暮らしでも食事の楽しさを取り戻せるコミュニティを目指しています。

---

##  開発背景・思い

休日になると「何を食べるか決められない」状態が続き、  
インスタント食品ばかりになってしまった経験から、  
**“決める負担を減らすアプリ”** を作りたいと考えました。

また、一人暮らしでは他の人の食事が見えず、  
食生活がマンネリ化しやすい問題があります。  
SNS機能で昼食を共有することで、  
**新しい発見や楽しさを生む場** を作りたいという思いがあります。

---

##  想定ユーザー

- 一人暮らし or 実家暮らしの社会人  
- 休日の昼食を自分で用意している人  
- 食事の決定に疲れている人  
- 他の人の昼食を参考にしたい人  

---

##  利用イメージ

1. アプリを開く  
2. 「和食 × 米」などのカテゴリを選択  
3. 料理候補が一覧表示  
4. 気分に合うものを選ぶ  
5. 実際に食べたら写真とコメントを投稿  
6. 他ユーザーの投稿をフィードで閲覧  

→ **決定疲れからの解放 × コミュニティの楽しさ**

---

##  差別化ポイント

### ✔ 1. 「決める」ことに特化したシンプル設計  
- 冷蔵庫の中身や好みを細かく聞かない  
- 大カテゴリ＋主食だけで候補を提示  
- 最短で昼食を決められる

### ✔ 2. SNS機能で「みんなの昼食」が見える  
- 写真・料理名を投稿  
- 他ユーザーの投稿をフィードで閲覧  
- 一人暮らしでも食事の楽しさを共有できる

##  機能一覧（MVP → 本リリースまで反映済）

### ■ MVPリリース機能（実装済）

| 機能名 | 内容 |
|--------|------|
| カテゴリ選択機能 | 和洋中＋主食カテゴリを選択 |
| 料理名一覧機能 | 選択カテゴリに紐づく料理名を一覧表示 |
| 選択記録機能 | ログインユーザーが過去の選択を閲覧 |
| ユーザー認証 | Devise によるログイン・新規登録 |

---

### ■ 本リリース機能（実装済）

| 機能名 | 内容 |
|--------|------|
| 投稿機能 | 食べた昼食の写真・料理名・を投稿 |
| フィード機能 | 他ユーザーの投稿を一覧表示 |
| 料理名による絞り込み | 投稿一覧を料理名でフィルタリング |
| 検索機能 | 料理名の部分一致検索 |
| ドロップダウン検索 | 投稿画面で料理名を検索して選択 |

---

##  未ログインでも利用できるページ

| 機能 | 未ログイン利用可？ | 理由 |
|------|---------------------|-------|
| カテゴリ選択 | ○ | 決定支援は誰でも使えるようにするため |
| 料理名一覧 | ○ | 昼食候補の閲覧は制限しない |
| 投稿閲覧（フィード） | ○ | コミュニティの雰囲気を見てもらうため |
| 投稿作成 | × | 認証が必要 |
| 選択記録 | × | 個人データのため |

→ **未ログインでもアプリの価値を体験できる設計**
